What do these columns mean?

Format is the version of Tryst's database inside the backup. Newer Tryst versions use higher numbers.

Fingerprint is the first characters of the file's SHA-256 checksum. If another copy has the same fingerprint, it is byte-for-byte the same file.

How do I restore a backup?

Download the file, copy it to your phone, and open it from Tryst's restore screen with the password it was made with. The download is the exact file Tryst created, unchanged.
